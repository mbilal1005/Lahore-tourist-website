# Visit Lahore

A multi-page tourist guide website for Lahore, Pakistan. Built with vanilla HTML, CSS, and JavaScript — no frameworks or build tools required.

## Pages

| Page | File | Description |
|------|------|-------------|
| Home | `index.html` | Landing page with background video, intro text, and blog carousel |
| Restaurants | `resturant.html` | Restaurant recommendations in Lahore |
| Food & Drinks | `food.html` | Overview of food and drink options |
| Shopping | `shopping.html` | Shopping guide |
| Hotels | `hotel.html` | Hotel recommendations |
| Blog | `blog.html` | Articles and guides about Lahore |
| Cinemas | `cinemas.html` | Cinema listings |
| Calendar | `calender.html` | Events and activities |
| Booking | `booking.html` | Booking page |
| Information | `information.html` | Practical travel information |
| Sources | `kilder.html` | Image and content sources |

## Features

- **Fixed navbar** with dropdown menus for Explore, Food & Drinks, and Information
- **Navbar scroll effect** — navbar background appears when the user scrolls down the page
- **Hero video** — autoplaying background video on the homepage
- **Blog carousel** — horizontally scrollable blog card list with previous/next navigation buttons
- **Book now button** — prominent CTA linking to the booking page
- **Responsive images** — multiple image sizes and formats across pages

## Tech Stack

- **HTML5**
- **CSS3** — custom properties, flexbox, CSS grid, transitions, scroll snapping
- **JavaScript** — vanilla JS for scroll events and carousel navigation

## Getting Started

No installation or build step needed. Just open `index.html` in a browser:

```bash
open "Turist prosjekt/index.html"
```

Or drag and drop `index.html` into any browser window.
